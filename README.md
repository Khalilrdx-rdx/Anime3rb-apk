# Anime3rb Android

تطبيق Android بسيط يفتح https://anime3rb.com/ داخل WebView.

## البناء
يمكن بناء نسخة Debug من GitHub Actions عبر تبويب Actions ثم اختيار Build Anime3rb APK ثم Run workflow.
هذا المشروع أولي؛ لا يضمن تشغيل كل مشغلات الفيديو أو خدمات الطرف الثالث، وقد تتغير سياسة الموقع أو قيود WebView.
